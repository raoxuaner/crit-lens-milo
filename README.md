# Crit Lens — Milo Robot Design Workbench

An interactive design prototype for comparing concepts, refining robot components, and exploring when an AI suggestion should appear during physical assembly.

- Work through **Keep**, **Explore**, and **Constraints** to build a design brief.
- Compare the rear cantilever, adjustable slide rail, and compact fixed hinge. Select a concept and confirm the branch to open its rendered components and editable dimension targets.
- Open **Prototype Lab** to try two suggestion timings during assembly.

This static demo uses prepared suggestions and concept renders. It needs no API key or server. Project edits are stored in the current browser.

To publish, put the files at the root of the GitHub repository and select **Settings → Pages → Deploy from a branch → main → / (root)**. For a local preview, serve the folder over HTTP rather than opening the HTML file directly.
